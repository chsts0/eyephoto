# EyePhoto

Редактор снимков радужки для студии. Windows.

## Что умеет

Редактор устроен как фотошоп, только без лишнего: документы во вкладках,
слои, панель инструментов слева, панели справа, меню с привычными клавишами.

- Документ начинается с чистого листа (А6, А5, А4, А3 при 500 dpi) или
  с PSD-шаблона студии из выбранной папки.
- Снимки с камеры (ARW, а также JPG и PNG) кладутся в документ слоями,
  можно сразу несколько. Каждый встаёт зрачком в центр листа, круг по
  радужке предлагается сам.
- Окно проявки как Camera Raw: гистограмма, «Свет», «Цвет», «Смешение
  цветов». Текстура и резкость всегда на максимуме.
- Слои: порядок, видимость, непрозрачность, переименование, закрепление,
  обтравочная маска, объединение (Ctrl+E), сохранение в PSD (Ctrl+Shift+S).
- Инструменты: перемещение с размером и поворотом, овальная область, лассо
  («добавить к выделенной области»), восстанавливающая кисть, заплатка
  нейронкой, штамп, кисть, ластик, затемнитель и осветлитель по диапазону,
  зрачок, рука, масштаб.
- Полоска «Глаза»: щелчок показывает один глаз, «Оба» возвращает пару.
- Раскладки студии одной кнопкой: «Углы», «Целые», «По центру».
- Панель «Шаблоны»: шаблон открывается из листа с глазами, и глаза сразу
  встают в места под фото. Места берутся из скрытых образцов в PSD или из
  чёрных областей шаблона.
- История действий: в неё попадает всё, включая выделения.
- Сохранение JPEG в папку дня: `<папка>\ноябрь 2026\10.11\4-1233.jpg`.
  Цифра точки задаётся один раз, папки месяца и дня программа находит сама.

Нейронка (LaMa) работает без интернета. Файл модели весит 200 МБ,
скачивается один раз при первой ретуши и хранится отдельно от программы.

## Привычки из фотошопа

- Колесо листает вверх-вниз, Ctrl или Shift с колесом вбок, Alt с колесом масштаб.
- Пробел: рука. Ctrl+пробел щелчок: приблизить, Alt+пробел щелчок: отдалить.
- Alt + правая кнопка: влево-вправо размер кисти, вверх-вниз жёсткость. [ ] размер, Shift+[ ] жёсткость.
- Зажатый Ctrl с любым рисующим инструментом временно даёт перемещение.
- Удержание клавиши инструмента включает его, пока клавиша зажата.
- Перемещение: щелчок выбирает слой, щелчок мимо снимает выбор, Alt+перетаскивание копирует слой,
  цифры 1–0 задают непрозрачность. У кистей цифры задают нажим.
- Кисть: Alt+щелчок берёт цвет, Shift+щелчок ведёт прямую от прошлой точки.
- Лассо добавляет каждую обводку к выделению, Alt вычитает, щелчок снимает выделение.
- Затемнитель и осветлитель (O): диапазон, экспонир, защита тонов.
- Восстанавливающая кисть (J), заплатка нейронкой (Shift+J), у штампа и кисти «Выравн.».
- Tab прячет панели.

## Запуск для разработки

```
npm install
npm start
```

## Как выкатить обновление на все компы

1. Поднять `version` в `package.json` (например, `0.1.0` → `0.1.1`).
2. Влить изменения в ветку `main`.

GitHub Actions соберёт установщик и опубликует релиз. Установленные копии
проверяют релизы при запуске и раз в час, качают новую версию в фоне
и ставят её при закрытии программы.

Первая установка на новый комп: скачать `EyePhoto-Setup-x.y.z.exe`
со страницы Releases и запустить.

## Мак (для проверки)

В том же релизе лежит `EyePhoto-x.y.z-mac.dmg` для маков на Apple Silicon (M1 и новее).
Программа без платной подписи Apple, поэтому:

- при первом запуске: правый щелчок по программе → «Открыть» → «Открыть»;
  если мак пишет, что программа повреждена, в Терминале:
  `xattr -cr /Applications/EyePhoto.app`
- обновляется вручную: программа сама пишет внизу, что вышла новая версия,
  кнопка «Скачать» открывает страницу релиза.
