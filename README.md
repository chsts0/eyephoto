# EyePhoto

Редактор снимков радужки для студии. Windows.

## Что умеет

Редактор устроен как фотошоп, только без лишнего: документы во вкладках,
слои, панель инструментов слева, панели справа, меню с привычными клавишами.

- Документ начинается с чистого листа (А6, А5, А4, А3 при 500 dpi) или
  с PSD-шаблона студии из выбранной папки.
- Снимок с камеры (ARW, а также JPG и PNG) кладётся в документ слоем.
- Слои: порядок, видимость, непрозрачность, переименование, закрепление,
  обтравочная маска, выделение нескольких.
- Инструменты: перемещение с размером и поворотом, овальная область, лассо,
  заплатка нейронкой, штамп, кисть, ластик, затемнитель и осветлитель,
  зрачок, рука, масштаб.
- Проявка слоя: теплее и холоднее, оттенок, яркость, контраст,
  насыщенность, детали. Исходные пиксели не портятся.
- Раскладки студии одной кнопкой: «Углы», «Целые», «По центру»,
  «По местам шаблона».
- История действий с отменой и возвратом.
- Сохранение JPEG в папку дня: `<папка>\ноябрь 2026\10.11\4-1233.jpg`.

Нейронка (LaMa) работает без интернета. Файл модели весит 200 МБ,
скачивается один раз при первой ретуши и хранится отдельно от программы.

## Запуск для разработки

```
npm install
npm start
```

## Как выкатить обновление на все компы

1. Поднять `version` в `package.json` (например, `0.1.0` → `0.1.1`).
2. Влить изменения в ветку `main`.

GitHub Actions соберёт установщик и опубликует релиз. Установленные копии
проверяют релизы при запуске и раз в час, качают новую версию в фоне
и ставят её при закрытии программы.

Первая установка на новый комп: скачать `EyePhoto-Setup-x.y.z.exe`
со страницы Releases и запустить.
