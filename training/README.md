# Обучение нейронки на глазах студии

Нейронка (LaMa) дообучается на готовых глазах студии: на чистый глаз рисуются
ненастоящие блики и ресницы, модель учится стирать их обратно. Пары «до/после»
не нужны.

## 1. Собрать глаза

Скачать сборщик со страницы https://github.com/chsts0/eyephoto/releases/tag/tools-v1:
`EyeCollect-windows.exe` или `EyeCollect-mac.zip`.

Запустить, выбрать папку с готовыми фото (ту, где лежат папки месяцев) и папку,
куда сохранить. Нажать «Собрать». В конце получится `eyes_dataset_ДАТА.zip`.

На маке программа не подписана: первый раз открыть правой кнопкой → «Открыть».

## 2. Залить на Kaggle

1. Зарегистрироваться на kaggle.com и подтвердить телефон (без этого не дают
   видеокарту и интернет в блокноте).
2. Datasets → New Dataset → загрузить `eyes_dataset_ДАТА.zip`, видимость **Private**.
3. Code → New Notebook → File → Import Notebook → `training/eyephoto_train.ipynb`.
4. Справа: Accelerator — GPU T4 x2 (или P100), Internet — On.
   Add Input → свой датасет.
5. Save Version → Save & Run All (Commit). Можно закрыть браузер.

## 3. Забрать модель

Часов через 9–10 во вкладке Output версии лежит `out/eyes_lama.onnx` (около 200 МБ)
и картинки сравнения в `out/samples`. Модель скачать и положить на Google Диск,
дальше она выкладывается в релиз, и программы скачают её сами.

## Для разработчика

- `train.py` — обучение, проверка, выгрузка в ONNX (входы image, mask 512×512, как у старой модели).
- `lama_model.py` — генератор big-lama на чистом PyTorch, совпадает с моделью программы до 1e-5.
- `safe_ckpt.py` — загрузка весов big-lama без выполнения кода из файла.
- Проверка на процессоре: `python train.py --data eyes.zip --steps 6 --warmup 3 --eval-every 3 --batch 1 --workers 0`.
